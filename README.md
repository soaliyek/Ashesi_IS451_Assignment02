## Running the App
### Requirements
You must have Xampp installed

### Xampp
- Launch Apache and MySQL from the Xampp Control Panel
- Copy the SQL Schema Code from database/schema.sql
- Open phpMyAdmin
- Select the SQL option, and paste the schema code
- Run to create the database and populate the tables and seed data

### ENV
- Create a .env file in the root directory
- Paste the content of .env.example into the .env
- modify the attributes to match your database password, user, etc...

### On localhost
Open a browser that supports passkey operations
Type localhost/Ashesi_IS451_Assignment02 and ENTER
